# Session note

Created: {{DATE}}. The shape of every session note. Copy it to `areas/<area>/notes/<yyyy-mm-dd>_<topic>.md`, fill the five lines, commit by exact path.

```
DATE: <yyyy-mm-dd>
WHAT: <what was done, one or two sentences>
DECIDED: <decisions taken, or "nothing"; each also a line in decisions.md>
OPEN: <what is left open, or "nothing">
FILED: <paths committed in this session, or "nothing">
```

Five lines. Longer only when the person asks for the long version.
